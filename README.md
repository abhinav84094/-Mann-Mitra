## 🌟 Project Overview

**Mann Mitra** is a modern, responsive mental wellness platform designed to provide safe, confidential, and empathetic emotional support. The platform creates a judgment-free space where individuals can openly discuss personal challenges including relationships, career stress, anxiety, depression, and emotional struggles.

**Tagline:** *"You're Never Alone - Someone Will Listen"*

### Vision
To build a compassionate digital community that normalizes mental health conversations and provides accessible emotional support to everyone, regardless of their background or circumstances.

### Core Mission
- Provide a safe, confidential space for peer support
- Combat loneliness and emotional isolation
- Empower individuals through compassionate listening
- Make mental wellness accessible to all

## 📖 Installation Guide

### Local Development Setup

#### Step 1: Clone Repository
```bash
git clone https://github.com/abhinav84094/-Mann-Mitra.git
cd -Mann-Mitra
```

#### Step 2: Directory Structure
Ensure your project has the following structure:
```
project-root/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── scripts.js
└── assets/
    └── images/
```

#### Step 3: Local Server (Recommended)

**Using Python 3:**
```bash
python -m http.server 8000
# Visit http://localhost:8000
```

**Using Node.js (http-server):**
```bash
npm install -g http-server
http-server
# Visit http://localhost:8080
```

**Using PHP:**
```bash
php -S localhost:8000
# Visit http://localhost:8000
```

#### Step 4: Development
- Edit HTML in `index.html`
- Modify styles in `css/style.css`
- Add interactivity in `js/` files
- Test in multiple browsers
- Use DevTools (F12) for debugging
